# Everyday Things, Two Lines, Longer Run

Deterministic `program/v1` entry for the [make.fun Everyday Things, Two Lines, Longer Run](https://make.fun/r/41fw6r6c) competition.

## Usage

```bash
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

Writes the two-line UTF-8 explanation to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set locally).
